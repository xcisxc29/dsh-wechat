# 使用手册

**用微信遥控你的电脑。** 手机上发消息，电脑上的 DSH 干活。

不需要懂技术，照着做就行。全程大约 5 分钟。

---

# 一、它能帮你做什么

## A. 出门在外，电脑替你干活

### 场景 1：不在电脑前，也能让电脑干活

出门前电脑上跑着 DSH。地铁上想起来一份文件要改，发条微信：

```
把 报告.md 里第三节的日期改成今天，然后发给我
```

**电脑上改好，文件作为附件发回你的微信。** 你不用打开电脑。

### 场景 2：让它查完东西直接告诉你

```
帮我查一下这个项目依赖里有没有安全漏洞，有的话列出来
```

DSH 在电脑上执行，结果发到微信。手机上读结论即可，不用看终端。

### 场景 3：跑长任务，跑完通知你

```
跑一遍测试，跑完了把结果告诉我
```

你可以去做别的事。DSH 跑完把结果发到微信。

### 场景 4：把电脑上的东西发到手机

```
把桌面上的 截图.png 发给我
把 D:\项目\报告.docx 发我
```

**不用先复制到哪儿**，直接说路径就行。图片出现在微信里能看能存，其他文件是附件。

---

## B. 锁定电脑后离开，手机全程控制 ⭐

**这是最实用的一个用法。**

你准备出门，但不想让电脑一直亮着屏幕（也不安全）。**按 Win+L 锁屏，然后走人。**

```
（锁屏前，电话或提前在微信里说）
帮我把这个项目重构一下，需要我决定的地方问我

（你锁屏出门，路上手机里回它的问题、看它的结果）
```

**锁定屏幕不影响 agent**：DSH 和 agent 都在后台继续跑，网络也照常。**你手机上完全控制它。**

### ⚠️ 但有一条必须分清

| 你做的 | agent 还能干活吗 |
|---|---|
| **锁定屏幕**（Win+L） | ✅ **照常工作** |
| **睡眠** | ❌ **停止**——CPU 被挂起，agent 也跟着停 |
| **休眠 / 关机** | ❌ **停止** |
| **合上笔记本盖子** | ⚠️ **看你设置**——默认常是"睡眠"，那就停了 |

**所以**：出门前**锁定屏幕**，**别让它睡眠**。

**检查一下**：设置 → 系统 → 电源，把「接通电源时」的睡眠设为**从不**（笔记本插电时）。合盖动作也检查一下是不是设成了"不采取任何操作"。

> **为什么要锁屏**：agent 在你电脑上有相当高的权限。锁屏不影响它工作，但能防止**路过的人**看到或操作你的桌面。

---

## C. 在电脑上干活，结果发到手机 ⭐

**你在电脑前跟一个对话干活，中途要出门，让它把结果发你微信。**

```
你（在电脑上的某个对话里）：这个构建跑完通知我，我先出去一趟

（你走了）

DSH → 你的微信：构建完成了，3 个警告，没有错误。
```

**注意**：这个对话**不是**微信绑定的那个，但**它照样能推到你手机**（默认开启）。

**这正是这个插件的价值**：不是"只能在微信对话里用"，而是**电脑上任何对话都能给你发消息**。

> **⚠️ 但有个前提**：电脑上别的对话**遇到要问你的地方，问题只弹在屏幕上**——你不在就卡住。
>
> **所以要么**先把这个对话设成「完全访问」（它就不问了），**要么**把这种活放到微信里交代。详见第五节。

---

## D. 手机上处理需要你决定的事

### 场景 5：权限询问，手机上点一下就行

DSH 干活时如果需要许可，**问题直接发到你微信**：

```
DSH：需要你的许可才能继续
     1. 允许
     2. 拒绝

你：1

DSH：好的，继续。
```

**多个选项也一样**，回个编号。

> 默认情况下微信来的对话是「完全访问」，它**不会**问你。想让它问，在设置里改。

### 场景 6：让它先问你，再动手

```
你：把 uploads 目录里三个月前的文件都删掉——先跟我说要删哪些

DSH：我要删这 12 个文件：
     ...

你：可以

DSH：删完了。
```

---

## E. 一个微信，管好几摊事

### 场景 7：同时推进多个任务

微信里只有一个聊天窗口，但**背后可以是好几个互不干扰的对话**：

```
你：/list

DSH：你的微信对话（共 3 个）
     1. 改登录 bug        3f8a1c2b   2 分钟前
     2. 写周报            9d4e7f01   1 小时前
     3. 整理资料          1c2d3e4f   昨天
       ← 当前

你：/switch 2

DSH：已切换到「写周报」。
```

**每个对话有自己的上下文**，互不污染。出门路上可以挨个推进。

---

## F. 定时和提醒

### 场景 8：让它定时叫你

```
每小时给我发一次当前时间
每天早上 9 点提醒我今天要做什么
10 分钟后叫我
```

**管理**：

```
看看我设了哪些定时任务
删掉那个每小时的提醒
```

> **提醒**：定时任务会**真的跑一轮 AI**，有 token 消耗，而且每次内容可能不同。想省钱就说清"只回一句话"。

详见**第五节「让它主动通知你」**。

---

## G. 各种输入方式

### 场景 9：拍张照片让它看

手机拍一张报错截图发过去，然后：

```
这个错误怎么解决
```

**图片和文字可以一起发**——先发图，紧接着发文字，会**合并成同一条任务**处理（默认等 10 秒）。

**也可以**：拍白板、拍纸质文件、拍实物，让它读。

### 场景 10：用语音交代

```
（按住说话）帮我把这个季度的数据整理成一个表格
```

**说比打字快**，特别是走路或开车停靠时。

### 场景 11：引用某条消息继续问

微信里**长按它发过的某条消息 → 引用**，然后问：

```
这条里的第二个方案为什么不行？
```

**它能找回那条消息的内容**，不用你重复粘贴。

### 场景 12：让它主动读电脑上的东西

```
看一下 logs 目录里今天最大的那个日志，前 50 行有什么问题
把那个 Excel 的第二个 sheet 读出来，列成 markdown 发我
```

## 和别的方案比，它有什么不一样

| | |
|---|---|
| **不用 OpenClaw** | 直接对接微信官方的机器人接口 |
| **不需要公网 IP** | 你的电脑主动往外连，所以路由器、公司网络、4G 热点都不影响 |
| **不需要服务器** | 就在你自己的电脑上跑 |
| **扫码一次，长期有效** | 电脑重启也不用重新扫 |
| **锁屏也能用** | 锁屏不影响 agent，出门前锁一下更安全 |
| **任何对话都能找你** | 不只是微信那个对话，电脑上任何对话都能推到你手机 |

# 二、安装

## ⚠️ 先记住这个名字

**要装的名字是：**

```
dsh-wechat-plugin
```

**注意最后有个 `-plugin`，别漏。**

**为什么强调**：这个仓库叫 `dsh-wechat`（少一个 `plugin`），但**包名必须带 `plugin`**。npm 上另有一位作者的插件就叫 `dsh-wechat`——**装错名字得到的是别人的作品**。

> **最保险的做法**：**复制上面那行**，不要凭记忆手打。

---

## 前提

- 电脑上装了 **DSH 桌面端**——本插件**针对 `0.2.0-rc.2` 开发和实测**（当前版本），
  **并会随桌面端的更新持续跟进**。不少社区插件随着 DSH 升级已经不能用了，这个是一直维护的
- 这台电脑**保持开机**，而且**不要让它睡眠**（**锁屏没关系**，见第一节 B）
- 手机上有**微信**

## 步骤

**1.** 打开 DSH，点侧栏的 **「插件」**，再点 **「添加插件」**

**2.** 在输入框里**粘贴**（不是手打）：

```
dsh-wechat-plugin
```

**3.** 点安装。装完点 **「立即启用」**

**4.** **重启 DSH**（关掉再打开）

> **为什么必须重启**：插件在 DSH 启动时加载，装了不重启不会生效。

---

# 三、第一次使用：扫码绑定

**1.** 打开 **设置 → 微信**（DSH 设置里的「微信」那一项）

**2.** 点 **「开始扫码」**，屏幕上会出现一个二维码

**3.** 用**手机微信**扫这个二维码

**4.** 手机上会提示确认，点确认

**5.** 页面上显示 **「已连接微信」** 就好了

## 试试看

在微信里找到那个机器人，发一条：

```
你好
```

**几秒内应该收到回复。** 收到就说明全部配好了。

> **发的第一条消息会成为这个对话的名字。** 比如你发「修一下登录」，这个对话就叫「修一下登录」。

---

# 四、能发什么

## 文字

直接发。DSH 会当成任务来做。

```
看看今天的日志里有没有报错
```

## 图片

**直接发照片**，DSH 会收到这张图。

手机上拍一张报错截图，发过去，然后：

```
这个错误怎么解决
```

**图片和文字可以一起发**——先发图，紧接着发文字，它们会**合并成同一条任务**处理（默认等 10 秒）。

> **为什么这样设计**：你常常先发个图、再补一句说明。如果第一条图立刻处理，你补的那句就变成了第二次不相关的问题。

## 文件

**发任意文件**（文档、压缩包、代码），DSH 收到并保存在电脑上。

```
帮我看看这个 Excel 有什么问题
```

## 语音

**发语音也可以。** 如果电脑上装了语音转文字组件，会先转成文字；没装也会把语音交给 DSH 处理。

## 视频

发视频，DSH 收到并保存。

---

# 五、让它把东西发回来

**直接要求就行**：

```
把结果发给我
把那张图发过来
生成一个表格文件发我
```

| 它发什么 | 你在微信里看到什么 |
|---|---|
| 图片 | 一张照片，能点开看 |
| 视频 | 能直接播放的视频 |
| 其他文件 | 文件附件，能点开或保存 |

**回复太长时会自动变成文件**：超过 4000 字，会发一个 `.md` 文件给你，**不会截断**。

## 文件在别的地方，也能直接发

**不用复制、不用挪位置。** 直接说文件在哪就行：

```
把桌面上的 报告.docx 发给我
把 D:\项目\手册.md 发我
```

DSH 会直接发过来。**桌面、项目文件夹、任何位置都行。**

> **一个安全提醒**：也正因为这样，**agent 能读到什么文件，就能发出什么文件**。所以别在能给它发消息的人里，放进不该看到你电脑文件的人。

---

## 让它主动通知你（重要）

**不用等你问，它可以主动发消息到你微信。**

### 例子：你在这边干活，然后出门

```
你：这个构建跑完通知我，我先出去一趟

DSH：好，跑完我发你微信。
```

构建结束时，消息就到你手机上了。

### 例子：定时提醒

**可以定时。** 直接说：

```
每小时给我发一次现在几点
```

或者更有用的：

```
每天早上 9 点提醒我今天要做什么
```

支持这些频率（说大白话即可，DSH 会自己选）：

| 你说 | 它做 |
|---|---|
| "10 分钟后叫我" | 一次 |
| "每小时" / "每 30 分钟" | 重复 |
| "每天早上 9 点" | 每天 |
| "每周一早上" | 每周 |

### 要精确的间隔，就用"定时任务"

**这里有个实测出来的区别**，值得知道：

| 你的说法 | 实际精度 |
|---|---|
| 「**每 10 秒**给我发一条」 | 由 DSH 调度，**接近精确** ✅ |
| 「给我发一条，等 10 秒，再发一条…」 | 每条之间还夹着它办事的时间，实测**16–19 秒** |

**想准，就用"每 N 秒/分钟/小时"这种说法**——那会建一个真正的定时任务，由 DSH 自己按时间叫醒，不受别的工作影响。

**管理定时任务**：

```
看看我设了哪些定时任务
删掉那个每小时的提醒
```

### ⚠️ 两个要知道的点

**① 定时任务会真的跑一轮 AI**，不是固定发一句话。所以**有 token 消耗**，而且**每次内容可能不同**。

想省钱就说清楚：

```
每小时发一次当前时间，只回一句话，别的都别做
```

**② 定时任务建在哪个对话，就在哪个对话里执行。**

所以**在微信里建的就发到微信；在电脑上的对话里建的就发到电脑**。要发到手机，就在微信里说这句话，或者在电脑上的对话里说（见下）。

### 电脑上的对话也能发到你微信

**默认开启。** 所以你在电脑上让我干活，我可以直接推到你手机：

```
你：改完这个文件告诉我

（你继续做别的事）

DSH → 你的微信：改完了，改的是第 3 节的日期。
```

**想关掉**：设置 → 微信 → 把 **「允许其他会话推送到微信」** 关掉。关掉后只有微信对话自己那个会话能发。

> **代价**：开着的话，**这台电脑上任何会话都能给你发消息**。这是有意的设计（否则"做完了通知我"就没法实现），但你该知道。

### 离开电脑前，务必看这一节

**有一件事会毁掉上面所有便利：权限询问。**

| 你在哪个对话干活 | 权限询问出现在哪 | 你不在电脑旁会怎样 |
|---|---|---|
| **微信绑定的那个对话** | ✅ **发到你微信**，手机上回一个数字就行 | 正常 |
| **电脑上的别的对话** | ❌ **只弹在电脑屏幕上** | ⛔ **卡死**——它等你点，而你不在 |

**为什么不一样**：权限询问只由**微信绑定的那个对话**认领并转发。别的对话的询问留在桌面，谁都看不到。

> 日志里就是这样：`not-a-wechat-session -> delegate`（不是我管的会话 → 交给桌面）。

---

## 所以，离开电脑前按这两条做

### ① 要在电脑上的对话里干活，并让它做完通知你 → **先把那个对话设成「完全访问」**

**因为推送能到手机，但"要不要允许"这个问题到不了。**

设成完全访问后，它就不再问，能一路做完并主动通知你。

```
（在电脑上那个对话里）
把当前对话的权限设为完全访问，然后改完这个文件发我微信
```

> **注意**：设置页里那个「微信对话的权限」**只对微信新建的对话生效**。电脑上已有的对话要在 DSH 自己的权限设置里改，或者直接这样跟它说。

### ② 如果你预计它会**中途问你**（选方案、要不要删、走哪条路）→ **先在微信里说这件事，再离开**

**别在电脑上的对话里交代这种活。** 因为你一走，它问到一半就没人答。

**正确做法**：在**微信**里给机器人下这个任务。这样：

- 它问的时候，**问题发到你微信**，你手机上直接选
- 做完的结果也**自动发到你微信**

```
（在微信里）
帮我把 report 目录整理一下，需要我决定的地方就问我
```

**它问 → 你答 → 它继续 → 结果发你**，全程在手机上闭环。

---

## 一句话记法

| 你的活是… | 在哪说 |
|---|---|
| **做完就行**，不需要你中途决定 | 电脑上哪个对话都行（**但要设成完全访问**） |
| **可能要你拿主意** | **微信里说**（或者先把那个对话绑到微信） |

**分不清就一律在微信里说**——多打几个字，胜过回来发现它卡了一小时。

---

## ⚠️ 微信会话会超时 —— 但消息不会丢

**微信给你的机器人一个"会话有效期"。一段时间没有新消息，它就失效了**——失效后**主动推送会被拒绝**。

**实测**：最后一条消息之后，推送有时几分钟就失效，有时二十多分钟还能发。**具体多久不由我们控制**，所以别依赖它。

---

### 好消息：被拒的消息会**排队等你**

**这是这一版新增的。** 窗口关闭时，推送的内容**不会被丢掉**，而是排队保存起来：

```
（你不在，窗口已关闭）
DSH：构建完成了  → 被拒 → 自动排队

（你回来，在微信里发一句"在吗"）
你：在吗

DSH：构建完成了          ← 排队的消息先补发给你
     之前有 1 个排队发送的文件已经找不到了：报告.docx

DSH：在的，有什么需要？   ← 然后才回你刚才那句
```

**所以现在是"延迟"，不是"丢失"。** 你下次拿起手机发一句话，积压的通知就到了。

**排队规则**：

| 项 | 规则 |
|---|---|
| **补发时机** | 你下次在这个微信对话里发消息时，**先补发，再回你** |
| **最多存** | 20 条（超了丢最旧的） |
| **存多久** | 24 小时（超了自动丢弃） |
| **文件丢了怎么办** | 会**明确告诉你**哪个文件找不到了，不会让你干等 |
| **其他失败** | 网络断了、文件不存在这类**会直接报错**，不排队——因为它们重试也不会成功 |

> **文件是"记住路径"而不是"存一份"**。所以排队期间如果你**删了那个文件**，补发时就不在了——但你会收到明确提示。

---

### 那还需要注意什么

**① 排队不是万能的**：消息要等你**发一条微信**才会到。所以"出门两小时，两小时后自动收到通知"**仍然做不到**——除非你在这期间碰过微信。

**② 想更主动，用定时任务**：

```
每小时给我发一次当前时间
```

每次唤醒都算一次活动。**但**如果会话已经超时，定时任务那次的推送**也会进队列**——所以还是等你回来。

**③ 最稳的做法**：需要长时间离开时，**把要做的事在微信里交代**。你在微信里的每条消息都在续期。

---

# 六、多个对话怎么管

**一个微信对话，可以对应电脑上多个不同的 DSH 对话。**

比如：一个对话在做项目 A，另一个在做项目 B。微信里只有一条聊天，用指令切换。

## 指令

在微信里**直接发**这些：

| 指令 | 作用 |
|---|---|
| `/new 修复登录` | 新建一个对话，名字叫「修复登录」 |
| `/list` | 列出所有对话（带编号） |
| `/list all` | 列出全部，包括别的工作区的 |
| `/switch 3` | 切到编号 3 那个 |
| `/current` | 我现在在哪个对话 |
| `/cancel` | 停下正在跑的任务 |
| `/help` | 显示这份列表 |

**空格可以省**：`/switch3`、`/switch 3`、`/switch:3` 都一样。

**一个例子**：

```
你：/list

DSH：你的微信对话（共 2 个）
     1. 修复登录            3f8a1c2b  2 分钟前
     2. 写周报              9d4e7f01  1 小时前
       ← 当前

你：/switch 2

DSH：已切换到「写周报」。
     9d4e7f01
```

## 说大白话也行

**记不住指令没关系**，直接说：

```
换个对话
看下有哪些对话
停一下
新建一个对话
```

DSH 会先告诉你它要做什么，你回复确认，它再执行。

> 想省掉这道确认：设置页里把 **「指令操作前需要确认」** 关掉。

# 七、手机上看不到权限弹窗？（重要）

## 以前的问题

DSH 执行命令前有时要问你"允许吗"。**那个询问原本只出现在电脑屏幕上**——你在手机上，就永远卡住。

## 现在

**权限询问会发到你的微信**，回一个数字就行：

```
DSH：需要你的许可才能继续
     1. 允许
     2. 拒绝

你：1
```

**多选提问也一样**，回编号。

## 但默认情况下它不会问你

**微信来的对话默认是「完全访问」**——DSH 执行命令前不询问，直接做。

**为什么这样定**：权限询问会发到微信，然后任务就**停在那里等你回答**。你在手机上，本来就是为了不守着电脑——**一条卡在对话里等你回复的命令，等于没发过**。

**想让它问**：设置页里改 **「微信对话的权限」**（见下一节）。

> ⚠️ **这个设置只影响之后新建的对话。** DSH 在对话开始后**锁定权限**，改不了已有的。想用新设置，`/new` 建一个新的。

# 八、设置页怎么用

打开 **设置 → 微信**。一共两组：**连接** 和 **行为**。

## 连接

| 项目 | 作用 |
|---|---|
| **启用通道** | 总开关。关掉后不再收微信消息，但**凭据保留**——再打开不用重新扫码 |
| **已绑定账号** | 显示绑定了哪个微信号，以及是否在接收消息 |
| **扫码绑定** | 重新扫码（换微信号、或凭据失效时用） |
| **最近错误** | 出问题时看这里 |

**通道状态**会显示三种：

| 显示 | 意思 |
|---|---|
| 接收中 | 正常工作中 |
| 已停止 | 通道被关了 |
| 凭据已失效，需要重新扫码 | 需要重新扫一次 |

## 行为

**改完立即生效，不用重启**（第一项例外，见下）。

### 1. 微信对话的权限 ← 最重要的一项

**默认：完全访问。**

| 选项 | 效果 |
|---|---|
| **完全访问：不询问，直接执行** | DSH 干活前不问 |
| **自动审核：电脑上判断** | 让电脑上的自动审核决定，不确定时才问你 |
| **跟随 DSH 设置：和桌面端一样** | 用你给桌面端设的那套把关 |

> ⚠️ **只影响之后新建的对话。**

### 2. 指令操作前需要确认

**默认开启。** 说「换个对话」这类要求时，DSH 会先说要做什么，等你同意。

**关掉**：你说了就直接做，不追问。

### 3. 非文字消息等待时间（秒）

**默认 10 秒。** 收到图片/文件后等这么久，看你有没有补充文字。

- 等了 10 秒你没说话 → 单独处理附件
- 你在 10 秒内发了文字 → 合并成一条处理

### 4. 等不到文字就自动处理附件

**默认开启。** 关掉后，附件会**一直等你发文字**，不会自动处理。

### 5. 回复长度上限（字）

**默认 4000。** 超过就改发 `.md` 文件，**不截断**。

### 6. 回复合并窗口（毫秒）

**默认 1200。** DSH 的输出如果间隔小于这个值，合并成一条微信消息。

调大 → 更长更完整，但更慢；调小 → 更快，但可能拆成好几条。

### 7. 引用缓存条数

**默认 40。** 每个对话保留多少条已发消息，用来还原你「引用」的内容。

### 8. 渠道身份提示

**每条消息前自动附上的一段说明**，告诉 DSH「你在和手机上的用户说话」。默认内容建议不要清空——没有它，DSH 会以为你坐在电脑前，让你"打开某个路径"。

## 指令组

设置页里还列出了**全部指令和它们的作用**，忘了可以直接去那儿看。

# 九、常见问题

## 收不到回复

| 先看 | 怎么办 |
|---|---|
| 设置页「通道状态」 | 显示"已停止" → 把「启用通道」打开 |
| 同上 | 显示"凭据已失效" → 重新扫码 |
| 都正常 | 发任意消息试试；还不行就重启 DSH |

## 装了插件但设置页没有「微信」

- **重启过 DSH 了吗？** 装了不重启不生效
- 侧栏「插件」里能看到它吗？看不到说明没装成功
- 能看到但没启用 → 点「立即启用」

## 装完重启，DSH 起不来了

打开这个文件看原因（里面有完整错误）：

```
C:\Users\<你的用户名>\.dsh\wechat\boot.log
```

## 手机上一直收不到权限询问

**这是正常的**——默认「完全访问」，它不问。想让它问，去设置页改「微信对话的权限」。

## 换了新的微信号想重新绑定

设置 → 微信 → **重新扫码**。

> ⚠️ **一个微信号只能绑一台电脑。** 用同一个微信号在第二台电脑上扫码，**第一台会被顶掉**。想两台同时用，需要两个不同的微信号。

## 电脑关机或休眠了，还能用吗

**不能。** 链路是"你的电脑主动连出去"，电脑关机或 DSH 没运行，微信这边就没有响应。

## 会不会很耗流量

**几乎不耗。** 只是收发文本和文件本身；图片、视频走的是微信自己的通道。

# 十、安全（请一定读）

## 最重要的一句话

**任何能给这个机器人发微信的人，都能操作你的电脑——而且不会问你。**

机器人可以执行命令、读写文件。

## 所以

**机器人绑的那个微信号，和能加到它的好友列表，就是安全边界。**

**没有白名单，而且是有意不做**——任何能给它发消息的人都能用。道理很简单：**你选择用微信控制这台电脑，就已经接受了"能给它发消息 = 能操作它"这条链**，再挡一道门只是同一件事说两遍。

## 你应该做

| 建议 | 说明 |
|---|---|
| **考虑用一个单独的微信号** | 不要把机器人绑在你的主号上 |
| **不要随便让机器人加好友** | 每一个好友都等于一个能操作你电脑的人 |
| **不放心就把权限改成「跟随 DSH 设置」** | 这样它会像桌面端一样先问你 |

## 最后一句话

**能给机器人发消息 = 能操作你的电脑。**

如果你觉得这个边界不合适，**不要装它**。
